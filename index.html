Method
  • Flow: OpenROAD-flow-scripts, synthesis to floorplan. No timing repair, so timing is pre-layout with an ideal clock.
  • Constraints: one clock on clk_i; input and output delay as listed in the build parameters.
  • SRAM models: fakeram, every cache memory is a FakeRAM2.0 macro and SRAM area is an SRAM estimate (on IHP SG13G2: the SRAM macros of the platform, and memories of fewer than 16 words as flip-flops); blackbox, the same netlist with the SRAM area left out; reference, the upstream SRAM models, with every memory as a flip-flop array counted as macro area.
  • kGE: standard-cell area divided by the NAND2 area of the technology.
  • Core Fmax: 1 / (clock period − worst register-to-register slack); this is the main speed figure. Fmax with I/O: from the worst path of all path groups. Input and output delays are a fixed share of the clock period, so this figure is often set by those constraints and not by the design.
  • Gate-level simulation: Verilator, zero delay, on the floorplan netlist with standard-cell models made from the Liberty files and behavioural models of the SRAM macros. The RTL runs the same programs. A program passes when it exits with status 0.
  • Area breakdown: synthesis netlist with hierarchy. A module below the keep size is merged into its parent; "(local)" is the logic of the parent itself.
