Method
  • Flow: OpenROAD-flow-scripts, synthesis to floorplan. No timing repair, so timing is pre-layout with an ideal clock.
  • Constraints: one clock on clk_i; input and output delay as listed in the build parameters.
  • SRAM models: fakeram, every cache memory is a FakeRAM2.0 macro and SRAM area is an SRAM estimate; blackbox, the same netlist with the SRAM area left out; reference, the upstream SRAM models, with the HPDcache memories as flip-flop arrays counted as macro area and the instruction cache memories absent.
  • kGE: standard-cell area divided by the NAND2 area of the technology.
  • Fmax: from the worst path of all path groups. Core fmax: 1 / (clock period − worst register-to-register slack).
  • Gate-level simulation: Verilator, zero delay, on the floorplan netlist with standard-cell models made from the Liberty files and the FakeRAM behavioural models. The RTL runs the same programs. A program passes when it exits with status 0.
  • Area breakdown: synthesis netlist with hierarchy. A module below the keep size is merged into its parent; "(local)" is the logic of the parent itself.
